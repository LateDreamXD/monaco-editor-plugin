# 本地化
Monaco 在评估时会解决它的大部分标签文本，所以必须在 `monaco-editor` 本身被加载**之前**加载语言包。Vue 组件通过懒加载导入 monaco，所以这样子是开箱即用的：

```ts twoslash [main.ts]
import { createApp } from 'vue';
import { useLocal } from '@latedream/monaco-editor-plugin/vue';
// ---cut-start---
// @ts-ignore
// ---cut-end---
import App from './App.vue';

useLocal('zh-cn');

createApp(App).mount('#app');
```

`useLocal` 返回了一个 `Promise`，但没必要 `await`：所有编辑器都会在 monaco 被导入前等待待处理的语言包。

支持的语言：`cs`, `de`, `es`, `fr`, `it`, `ja`, `ko`, `pl`, `pt-br`, `ru`, `tr`, `zh-cn`, `zh-tw`。英语是内置并且默认的。
